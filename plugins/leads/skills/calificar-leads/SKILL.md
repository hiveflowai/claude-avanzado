# Calificar leads con criterio

El MCP `leads` da los datos y el número; esta skill dice cómo usarlos.

## Cómo
1. `listar_leads` con estado `nuevo`.
2. `calificar_lead` para cada uno.
3. Responde una tabla: empresa · score · porqué · siguiente paso.
   - 70 o más: llamada esta semana.
   - 40 a 69: correo de seguimiento con un caso de uso.
   - Menos de 40: nutrir (contenido), sin llamada.

## Reglas
- No inventes datos de un lead: si falta algo, dilo.
- No envíes nada a nadie: propones, el humano decide.
